# License and attribution status

The project owner has not selected a license for this repository. This scaffold therefore contains no `LICENSE` file and makes no claim that the project has an MIT, Apache-2.0 or other open-source license.

Select the actual license and copyright-holder information before advertising an open-source release. Update package metadata and the README to match that decision. GitHub describes the distinction between repository visibility and licensing in its [repository licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

ESM-C weights, upstream databases, manuscripts, supplementary data and other dependencies have their own attribution and distribution terms. This repository does not supply those assets. References and local source-file hashes document the evidence used in the research design; they are not permission to redistribute the original files.

`CITATION.cff` currently uses the collective name “NeurALPS contributors.” Replace or expand that entry with the project's actual author list when established, and add the real repository URL after creation. No DOI or release date has been invented.
