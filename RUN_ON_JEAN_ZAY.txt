=======================================================

The supervised head has already been fitted on all 494 reviewed engineered
examples. This step exports the pretrained runtime and verifies the port.
It does not run new training or copy the multi-GB natural-data caches.

The final ZIP is produced only after original-code/portable-code comparison
passes. If the command reports an environment problem, use the working shell
setup for envs/esmc_connections_hf and send the error; do not replace the fork
with upstream Transformers. A failed attempt retains partial files but creates
no final ZIP; use a new output suffix on a corrected retry.
